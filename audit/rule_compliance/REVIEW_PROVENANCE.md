# Review provenance

| Stage | Available evidence and limits |
|---|---|
| Original generation | 120 archived outputs, identified by preserved source links and hashes. This preparation does not rerun model calls or certify historical session inputs. |
| Initial AI assessment | Fixed ledger with item IDs, source excerpts and evaluation fields. `review_completed` denotes completion of that recorded assessment, not human verification. |
| Focused contextual re-review | 19 initial-role cases and 3 prior-path cases in `data/adjudication/decisions.csv`; 6 clear amendments and 8 boundary amendments. AI contextual judgment. |
| Forty-item AI re-review | Separate diagnostic ledger and explanations. Human fields remain blank or explicitly unverified. 38 common IDs are checked against the current ledger. |
| Author methodology review | Revision 17 describes qualitative, non-blind review of the evaluation criteria informed by author comments. This is not a completed 40-item human coding exercise. |
| Independent human item coding | No verified item-level independent human coding record is integrated. No invented reviewer name, count, agreement score or reliability statistic. Old blank forms do not prove that no later human review occurred. |
| This preparation | Deterministic reaggregation, traceability, source/copy hashing and software error detection. It does not upgrade AI decisions into human ground truth. |

The manuscript's evaluator designation is an author-recorded label. Without preserved per-call logs it does not authenticate a fixed model snapshot, exact evaluation timestamp, settings or model version. The model used for this packaging session is not retroactively attributed to earlier evaluations.

An excerpt match checks where text occurs; a label replay checks that counts follow the recorded decisions. Neither independently establishes semantic correctness, human-equivalent behavior or historical validity of the generated scenario.
