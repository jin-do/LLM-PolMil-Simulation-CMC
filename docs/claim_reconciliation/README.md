# Revision 17 numeric claim reconciliation

This module compares the manuscript's numeric targets with the files generated by the public revision 17 reproduction code. `claim_spec.json` contains short labels, numeric values, paragraph/table/cell anchors, public input hashes, criteria and code paths, explicit record selectors, and denominator descriptions. It contains no unpublished manuscript prose, reviewer correspondence, author email, private file paths, or respondent rows.

After generating the results from the repository root:

```text
python -X utf8 audit/rule_compliance/code/reproduce_revision17.py --out reproduced
python docs/claim_reconciliation/code/verify_claims.py --repo . --results reproduced --out reproduced/claims
```

Python 3.10 or later and the standard library are sufficient. The verifier reads inputs and results; it writes only to the selected `--out` directory. The files are `claim_comparison.csv`, `claim_comparison.json`, and `claim_summary.json`. No network access, AI service, or private source folder is used.

The verifier selects records by named domain, analysis version, turn, case ID, question, system, or outcome category. It never finds a matching row from the target numeric value. Table A2 effect increments are read from exact preserved rule-path records. Table C1 uses actual-response aggregate sufficient statistics. Public-source hashes distinguish the disclosed copies from undisclosed original or private files.

The target inventory contains repeated prose statements and table cells. Its size is not a scientific sample, a count of independently validated findings, or a measure of evaluator reliability. `MATCH_REPRODUCED` means that the stated number matches the public fixed-input calculation or documented aggregate. It does not establish semantic correctness, human review, exact reproduction of the original LLM generation, or historical input-version binding. `NOT_REPRODUCED` identifies an explicit source-dependent boundary; it is not an assertion that the manuscript claim is false. `MISMATCH` and `ERROR` cause a nonzero exit status.

The recorded local preparation matched the statistical targets for Table 3, Table 4, Tables A1–A6, Table B1, and Table C1, subject to the A1 readability-threshold boundary below. Fixed marker observations are reaggregated; the original PDF text search is a separate task. The main numerical outputs use the retained labels and data, not a new full semantic reassessment.

The following source-dependent targets are recorded without a full automated reproduction claim:

- A1's 500-character readability threshold: the retained Boolean marker input does not carry the source text length; this replay does not extract each PDF again.
- Paragraphs p0068 and p0204: the historic operation of retrieving six PDFs and matching hashes cannot be certified by reaggregating its documented labels. The 19 initial and three continuation cases have structured records, but the whole composite statement retains this limitation.
- Paragraph p0087: the illustrative Claude-01 Turn 3 states require the cited source passages beyond the structured Turn 4 arithmetic example.
- Paragraph p0101: Gemini-28's narrative/log statement has linked evidence; this verifier does not newly recode its numerical source passages.
- Paragraph p0106: HR-003's three-path illustration is a source-interpretation claim, not a newly counted output here.
- Paragraph p0221: survey recruitment criteria and actual administration cannot be independently established from non-individual survey aggregates.

Anchors count direct body paragraphs and tables in revision 17 from one; table rows and cells also start at one. They are not rendered page numbers. The internal delivery retains the original manuscript text and its hash for location checking. The public package excludes that manuscript.
