# Archive design notes

This document describes what can be established from the archived materials. Its filename is retained for continuity; it should not be read as a verified, preregistered final-experiment specification.

## Recorded materials and system groups

The original public snapshot [d345e7f391bef6f6c60c52d2a5907f0d166384ba](https://github.com/jin-do/LLM-PolMil-Simulation-CMC/tree/d345e7f391bef6f6c60c52d2a5907f0d166384ba), retrieved on 5 September 2026, contains two actor-profile JSON files, a VDM, protocol and prompt documents, 120 PDFs, and aggregate coding materials. The PDFs are organized into four named system groups with 30 records each. The grouping does not independently authenticate exact provider versions, sampling settings, or execution independence.

The present work is a retrospective audit and reanalysis of those records. It adds no executions and does not estimate an experimental effect of changing information mode, prompt structure, or model architecture.

## Protocol variants versus executed conditions

The protocol describes a baseline, Self-Guided Restricted Learning, Curated Input, and Hybrid configuration. These are documented design variants. In this context, restricted "learning" is an archived label for instructions about information access, not evidence of model training or parameter updates.

The retained files do not establish a complete randomized or factorial assignment of these modes to the 120 records. They also do not supply a sufficient execution-by-execution configuration ledger to certify that one named mode alone was used throughout. No mode effect is estimated. A retrospective description of possible modes must not be converted into a verified treatment-assignment history.

The archive also does not substantiate a numerical pilot-run total or a complete chronology showing that a final configuration was frozen before every analyzed execution. This revision therefore does not retain claims about an unverified pilot count or reconstruct a missing configuration-freeze history.

## Prompted turns and generated branches

The archived prompt supplies an event sequence that includes missile discovery, naval interception/DEFCON 3, a U-2 shootdown, and a submarine/DEFCON 2 crisis. These supplied events are researcher-written scenario injections. They must be distinguished from candidate actions, reported triggers, and narrative continuations generated by the model.

The prompt requests several action combinations and at least three scenario reports. The coded data retain one outcome and one numeric vector per source run. The available coding documentation does not reconstruct the original rule for reducing multiple branches to that single record. The [provenance audit](provenance_audit.md) reports the mechanical crosswalk checks and two targeted source-passage concerns. Semantic provenance remains unresolved for all 120 rows; no replacement coding has been inferred.

## Scope of comparison

Perplexity Pro is a retrieval-augmented system condition, not a foundation-model-only treatment. The retained package does not reconstruct every retrieval or ranking decision. The three-group calculations therefore describe the same archived coding after excluding that system; they are exploratory sensitivity analyses, not a controlled isolation of retrieval effects.

Shared inputs, incomplete generation settings, nonrandom group labels, and unresolved coding provenance limit interpretation to the recorded material. The primary five-category tabulation and its sensitivities describe differences in archived workbook coding. They do not establish stable provider characteristics or crisis probabilities.

## Design artifacts with unresolved provenance

The original inputs retain later historical information despite an intended October 14 start, differing scale descriptions, and incomplete citation and influence-weight provenance. These issues are documented in [input artifact caveats](input_artifact_caveats.md). The exact input documents remain historical evidence; this revision does not replace them with a newly reconstructed protocol and claim that it was used for the old executions.
