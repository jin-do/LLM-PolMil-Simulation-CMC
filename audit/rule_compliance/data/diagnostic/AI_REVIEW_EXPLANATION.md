# 40항목 AI 재검토 — 원규칙·출력 대조

AI 재검토 기록일: 2026-09-20

## 이 문서가 하는 일

기존 40개 점검 항목을 “무엇을 요구했나 → 출력이 실제로 무엇을 했나 → 그 질문에 대한 판정은 무엇인가”로 다시 설명했다. 결과는 **AI 재검토**이며 인간 검토를 수행했다는 증거가 아니다. 사람의 검토자·날짜·판정·근거 칸은 모두 비워두었다. 기존 원장, 논문, Drive와 GitHub에는 변경을 가하지 않았다.

40건은 공통평가에서 선별한 38개 항목과 대표 사례 2개이다. 전체 1,320개 규칙 적용 건이나 전체 120회 실행의 정확도를 새로 평가한 자료가 아니다. 표본은 목적적으로 선별되어 있으므로 아래 건수를 전체 준수율·평가 정확도·인간–AI 일치율로 바꾸지 않는다.

**판정 기준**: C는 해당 항목의 이행이 근거로 확인됨, V는 적용되는 요구와 실제 출력의 명확한 충돌 또는 누락, U는 기록 부족이나 원규칙의 적용 범위가 불명확하여 결정하지 못함이다. 이 자료에서 NA를 새로 부여한 항목은 없다.

## 읽을 때의 핵심

‘대안을 만들었는가’와 ‘모든 대안의 로그를 남겼는가’, ‘부모경로를 다뤘는가’와 ‘그 상태값이 정확한가’, ‘지정 사건을 사용했는가’와 ‘사건 효과 계산이 맞는가’는 각각 다른 질문이다. 이들 가운데 하나에서 C를 받았다고 다른 질문까지 통과한 것은 아니다.

이미 종결 상태라고 기록된 경로의 적용 여부가 모호한 것과, 남아 있는 경로를 모델이 새로운 이유를 붙여 중단한 것은 구분한다. 목표·선호·믿음을 표현하는 언어와 실제 결과를 보장하는 언어도 구분하며, 단어 하나만으로 C/V를 주지 않는다.

## 이번 재검토의 범위

9월14일 40항목 카드, 원규칙 표와 보존 Prompt를 사용하고, 앞선 Work 재검증이 보존한 전체 PDF 텍스트에서 관련 턴과 전후 결과를 대조했다. 다섯 원본 PDF(CLA-01·CLA-19·GEM-28·PER-11·PER-21)의 바이트 해시가 카드의 해시와 일치했다. 화면을 직접 확인한 페이지와 개별 검토 범위는 원장 및 확인기록에 별도로 적었다. **35개 고유 실행 PDF 모두를 새로 내려받아 전 페이지를 화면 검수한 것은 아니다.** 일부 PDF를 직접 가져오려는 원격 요청은 실패했으므로 보존 추출문에 의존한 범위는 그렇게 표시한다.

이전 대화·카드의 설명을 이미 본 상태이고 같은 AI 작업 흐름의 재검토이므로 독립·블라인드 평가라고 부르지 않는다. 기존 판정과의 대조는 오류 위치를 설명하기 위한 것이며 정답표로 사용하지 않았다. GEM-16의 중단 사례는 처음에는 종료 적용의 불확실성으로 보류했다가, 전 턴 상태가 남아 있고 중단 근거가 새로 만든 비양립 가정임을 확인하여 V로 정리했다.

## 40항목 상세 대조

### HR-001 · CLA-13 · 준수

**확인할 질문:** 소련의 초기 대안과 주요 선택이 소련에 부여한 목표·성향과 맞는가?

**원래 요구:** 행동과 판단 근거를 해당 국가·행위자의 보존 프로필에 근거해 작성한다. 선호가 다르게 절충될 수 있지만 고정된 성향·권한·명시 제약을 임의로 바꾸면 안 된다.

**실제 출력:** 소련에 은밀한 배치 계속, 부인과 협상, 경계 강화라는 선택을 제시하고, 주요 경로에서는 미국의 봉쇄에 부인·협상으로 대응한다. 5쪽의 설명은 양측 지도자의 중간 수준 갈등회피를 언급한다.

**판단 이유:** 쿠바 보호·억지와 확전 회피를 서로 다른 방식으로 추구하는 선택이다. 갈등회피와 위험감수는 다른 속성이며, 이 문장의 중간 갈등회피는 보존된 소련 지도자 설정과 모순되지 않는다.

**이 판단에 포함되지 않는 것:** 소련의 초기 설정 대응에 대한 판정이다. 모든 가중치·수치·후속 선택의 정확성을 인증하지 않는다.

**근거 위치:** 1–5쪽. [보존 원본](https://github.com/jin-do/LLM-PolMil-Simulation-CMC/blob/6867755772bfb74dd56c211df8c9a399607b5419/runs/raw_logs/Claude_Opus_4/13.%20Strategic%20Decision%20Modeling%20Protocol.pdf)

**읽은 자료:** 보존 PDF의 이전 전체 추출문에서 지정 범위와 카드 발췌 대조. 

**이전 기록과의 관계:** 9월14일 카드 판정 유지(새로운 독립성·정확도 증명이 아님)

### HR-002 · CLA-01 · 위반

**확인할 질문:** 소련의 선택 근거가 원프로필의 성향값을 정확히 사용했는가?

**원래 요구:** 행동과 판단 근거를 해당 국가·행위자의 보존 프로필에 근거해 작성한다. 선호가 다르게 절충될 수 있지만 고정된 성향·권한·명시 제약을 임의로 바꾸면 안 된다.

**실제 출력:** 협상과 배치 중단이라는 선택 자체는 목표와 양립한다. 그러나 4쪽 주요 조합의 근거는 양측 지도자의 위험감수 성향이 모두 중간이라고 설명한다.

**판단 이유:** 보존 프로필의 소련 지도자 위험감수는 High이다. 협상을 선택해서 위반인 것이 아니라, 선택을 설명하면서 고정된 성향을 다르게 인용한 것이 위반이다.

**이 판단에 포함되지 않는 것:** 이런 속성 인용의 오류가 해당 실행의 모든 행동이 부적절함을 뜻하지 않는다.

**근거 위치:** 1–4쪽. [보존 원본](https://github.com/jin-do/LLM-PolMil-Simulation-CMC/blob/6867755772bfb74dd56c211df8c9a399607b5419/runs/raw_logs/Claude_Opus_4/1.%20Strategic%20Decision%20Modeling%20Protocol.pdf)

**이전 기록과의 관계:** 9월14일 카드 판정 유지(새로운 독립성·정확도 증명이 아님)

### HR-003 · CLA-19 · 준수

**확인할 질문:** 3턴에 실제 다룬 각 경로에서 주요 조합 외의 추가 행동 조합을 만들었는가?

**원래 요구:** 현재 처리하는 각 경로마다 주요 양국 행동 조합 하나와 추가 조합 하나 또는 둘을 제시한다. 각국의 행동 목록이나 기존 부모 경로의 개수와는 다르다.
