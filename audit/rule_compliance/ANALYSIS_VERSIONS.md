The governing chain is original judgments → six clear changes → eight boundary changes → Table 4/Table A4 → Table A6 turn counts. The generated `adjudication_change_history.csv` connects each amendment to the prior label, current label, source quote, page, decision ID and criterion version. The 22 focused-review entries are not 22 amendments: only the 14 patch entries alter labels. The 40 diagnostic entries are not 40 new independent observations.

The 2026-09-20 criterion clarification is a retrospective evaluation rule. It is distinct from the original generation rules and from future proposed path-preservation or precedence rules. No future rule is retroactively used to label past outputs.

The turn wrapper was added during this preparation (2026-09-22). Existing aggregation, deterministic calculation and adjudication functions are reused. Metric keys define domains because inherited free-text domain descriptions are not consistently populated. Turn fields are checked against the metric keys.
