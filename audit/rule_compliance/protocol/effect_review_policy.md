# 행동–효과·상태 갱신 보완 판정 기준

적용 원규칙은 P-EFFECT-01, P-VDM-01, VDM-E01…E08, VDM-CLAMP와 원 actor effect_rules다. 새로운 규칙을 만들지 않는다. 아래는 원문 의미를 대조하기 위한 감사의 조작적 판정 기준이며 과거 모델에 새 지시를 부과하는 것이 아니다.

1. 군사 공격·실제 보복/교전은 Strike, 배치·경계·방어 준비는 Defense_Prep과 대조한다. 공격의 준비·권한 부여만 있는 경우와 이미 공격한 경우를 구분한다. 선정된 가상 경로에서 예측한 행동·성과도 원래 생성 지시의 출력이므로 현실에서 일어난 일일 필요는 없다.
2. Diplomatic_Success는 서명된 최종 조약만으로 한정하지 않는다. 실제로 개통된 채널, 상대의 수락, 합의·검증된 이행 등 기록된 제한적 성과와 대응할 수 있다. 단순한 제안·기대·조건부 가능성과 기록된 성과는 구분하되 원정의가 특정하지 않은 성공 단계 경계는 모호성으로 기록한다.
3. Strong_Leadership, Alliance_Strengthening, Civil_Unrest 등은 실제 행동·기록된 반응과 대조한다. 사건명을 쓰거나 ‘규칙을 따랐다’는 자기진술만으로 준수하지 않는다. 역할·목표 절충과 다른 선택 자체는 오류가 아니다.
4. 행동 분류의 적합성, 적용 효과집합의 완전성, 개별 효과 상수, 상태 산술, 이전 상태 승계는 각각 다른 점검이다. 한 점검의 준수로 나머지를 인증하지 않는다.
5. 두 행위자/복합사건의 합산·순서·감쇠 방식이 원문에 특정되지 않았다면 원칙을 새로 정하지 않는다. 명시 연산은 독립 계산할 수 있지만, 임의 가중치·감쇠·상한을 새로 도입한 명시 기록은 원래 엄격 적용 의무와 따로 대조한다.
6. actor effect_rules 숫자의 절대값/증분 의미와 diplomatic_room의 Diplomatic_Support 변환은 당시 원규칙에 근거가 있는지 확인한다. 단순히 해당 숫자와 일치한다고 전체 집행을 준수로 판정하지 않는다.
7. 각 판정은 실제 검토한 원문 단위에만 적용한다. label 기반 추출에 잡히지 않는 표도 별도 확인한다. 미검토는 review_completed=false로 남겨 검증완료율에서 제외한다. rule_ambiguous, record_missing_or_incomplete, source_extraction_unresolved와 혼동하지 않는다.
8. 의미 판정은 AI 보조 원문 대조이며 독립 인간 평가가 아니다. 입력 파일 버전은 보존 입력 기준의 조건부 적용이며 실행시 파일바이트 동일성을 보장하지 않는다.
