# 후속 행위자 설정 감사: 판정 범위

원 actor JSON 153개 요구사항과 원 AHP 문서의 3개 보충 요구사항을 입력 목록에 먼저 공개했다. T2–T4의 보존 행동대안과 선택을 읽고, 국가 행동군의 목표·성향상 허용 여부와 개별 행위자의 관찰된 행위를 분리한다. 국가 행동의 허용 판정은 7개 기관의 모든 내부 숙의·정보 접근·명령권 집행의 확인을 뜻하지 않는다.

각 턴의 모든 보존 행동대안을 읽은 범위에서만 행동군 C를 부여한다. 강경·온건 대안은 선호와 목표의 허용 범위를 대조하며, 최고 가중치 행위자 선호와 다른 선택, 고위험 감수 행위자의 온건 선택만으로 V를 주지 않는다. 군부의 제안·준비는 무단 실행과 다르다. 대통령/정치 지도부의 승인 또는 독립 실행이 명시된 경우 권한 요구사항을 직접 대조한다. 승인 과정이 보이지 않는 국가 행동만으로 무단 실행을 단정하지 않는다.

행위자가 관찰되지 않거나 권한·정보·가중치의 해당 집행이 보이지 않으면 관찰 불충분 U로 기록한다. 이것은 모델 응답 전체가 불완전하다는 뜻이 아니다. 구체적인 필수 출력 누락 판정은 별도 절차 대장에서 유지한다. 전건이 발생하지 않은 조건부 규칙은 N/A이며, 원래 규칙의 충돌/적용 정의 부재는 rule_ambiguous U이다. 미검토를 자료 부족으로 기록하지 않는다.

의미 판단은 근거를 제시한 AI 원문 대조이며 인간 평가자에 의한 확인은 없다. 재실행 코드는 고정 주석의 원문 해시·인용·집계만 재현하며 의미 판단을 자동으로 다시 생성하지 않는다. 과거 실행과 입력의 버전 결합은 별도 불확실성으로 남고, C/V는 보존 공통 입력을 조건부로 대조한 결과다.
